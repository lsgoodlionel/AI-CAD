# 全套金标准规格

> 覆盖：轴线 / 图框 / 总说明 / 图名 / 柱梁板墙等构件 / 各专业标注。
> 目的：让「识别对不对」「模型与图纸对不对得上」这两个问题**可量化、可复核、可追溯**。

## 1. 一条设计决定：实体身份用轴号，不用坐标

    "1×A"   ← A 轴与 1 轴交点处的那根柱

**为什么不用像素/米坐标**：实测跨图位置对应率只有 1.6~4.7%
（`docs/MODEL_FIDELITY_AUDIT.md`），坐标系尚未统一。
用坐标做真值 = 把一个未解决的问题写进标尺里。

轴号是**图纸自带的寻址方式**（GB/T 50001 §8 定位轴线）：人能核对、
跨比例稳定、与坐标系是否统一无关。等坐标系统一后，轴号真值仍然有效。

## 2. 记录格式

一个 **GoldUnit** = 一处图纸范围（整图或一块切片）上，若干**对象类**各自的真值。

| method | 用于 | 真值形态 | 评分口径 |
|---|---|---|---|
| `count` | 只数个数 | 整数 | 绝对/相对误差、是否一致 |
| `instances` | 实体级 | 轴号身份 + 尺寸 | 精确率/召回率/F1、尺寸误差 |
| `text` | 图名、总说明 | 字符串 | 归一化后是否相同 |
| `fields` | 图框标题栏 | 字段映射 | 逐字段命中/错值/缺失 |

代码：`core/model3d/gold/{schema,score}.py`。数据：`data/model3d/gold/*.json`（**入库版本管理**）。

尺寸误差取**逐边最大**再对实体平均 —— GB 50204 卡截面尺寸是逐边卡的，
取平均会把 40 毫米的超差稀释成 20。

## 3. 什么样的真值才算数

    counts_toward_metrics = 未被排除 且（经人工复核 或 把握 ≥ 0.8）

**排除项留档不删**，并写明理由 —— 删掉就看不见协议在起作用。
已用过的排除理由：`非平面图` / `埋件图` / `三方不一致` / `不可判定`。

评分器对排除项**主动报错**而非跳过：调用方漏筛就该炸出来，
否则指标会凭空好看。

## 4. 采集协议（实战验证过）

1. **分层抽样**：按密度分档，不然会高估所有方法的成绩
2. **独立计数**：交给不看识别结果的第三方（GPT），一次一块
3. **三道格式闸**：`confidence` 非 0 / 必填分格 / 分格之和 = 总数
4. **人工逐块复核**：闸只能验自洽，验不了对错
5. **两两一致才采信**，三方各不相同 → 判不可判定并排除

第 3 步各挡下过一类无效响应；第 4 步不可省 —— 实测出现过
「总数正确、分格全错、而分格之和仍等于总数」。

## 5. 一个必须先答的问题：金标准在问什么

    「这块图上画了几个方块？」        → 4
    「这张图该给模型贡献几根柱？」    → 0

实测 G41（埋件平面布置图）上两者不同：那些方块是**预埋钢板**，
其对应的柱在结构平面图里已有，再造一遍就是构件重复。

**建模要的是第二问。** 每个对象类都必须先明确问的是哪一个。

## 6. 对象类清单与优先级

| # | 对象类 | method | 状态 | 为什么这个顺序 |
|---|---|---|---|---|
| 1 | columns（数量） | count | ✅ 72 单元 | 已完成，验证了协议本身 |
| 2 | **axes 轴线** | instances | ⏳ 下一步 | **位置真值的前提**：没有轴号就没有实体身份 |
| 3 | title_block 图框 | fields | ⏳ | 比例/图号/专业 —— 比例错会让所有尺寸错 |
| 4 | drawing_title 图名 | text | ⏳ | 图种判别与角色分派的输入 |
| 5 | columns（实体级） | instances | ⏳ | 升级第 1 项：从「几根」到「哪几根、多大」 |
| 6 | walls / beams / slabs | instances | ⏳ | 至今**零验证** |
| 7 | notes 总说明 | text | ⏳ | 已有 891 块重建文本，未验证 |
| 8 | 各专业标注 | instances | ⏳ | 标高/配筋/门窗编号 |

第 2 项是关键转折：**轴线金标准建成之前，第 5~8 项都只能停留在计数级**。

## 7. 现状（第 1 项）

72 单元：已核实 4 / 把握达标 36 / 未核实 15 / **排除 17**（理由随档）。
识别器在其上：平均绝对误差 9.29 → **1.49**，完全一致 1/55 → **31/55**。
