# 金标准判据（各对象类的「算/不算」定义）

**为什么要有这份文件。** 柱的精确率两次实测得到 0.59 与 0.22，相差近三倍。
排查后发现**不是识别器变了，也不是问法宽严** —— 是两批用了**不同的「柱」定义**：

| | 旧批 0.59 | 新批 0.22 |
|---|---|---|
| 带对角叉（×）的方块 | **算**（型钢混凝土柱，若在轴线交点）| 判读答「墙/梁」5~6 格 |
| 旁标 KZ / 600KZ6 柱编号 | **算** | 问法**禁止读编号**（怕字符转写不可靠）|

判据不同，数字就不可比。**同一对象类的所有批次必须引用本文件的同一条定义**，
批次命令里的判据段落从这里抄，改判据要在这里改并留版本记录。

## columns / column_outline —— 什么算「柱」

依据 GB/T 50001《房屋建筑制图统一标准》与结构制图惯例。

**算柱**

- 实心（灰或黑）或带剖面填充的**近方形**块，长宽比 < 2
- 落在轴线（细虚线／点划线）**交点**上
- 旁边标着 `KZ` / `KZ-D10` / `600KZ6` 这类**柱编号**
- **带对角叉（×）的方块**，若位于轴线交点且尺寸与周围柱相当 —— 型钢混凝土柱
- 倾斜（菱形姿态）但满足以上条件的，**算**

**不算柱**

- 细长的灰／黑条带 → 墙或梁
- **标高符号的黑色小三角（▶）**
- 门扇、门的开启弧线、窗的小填充块
- 楼梯踏步、坡道、栏杆
- 尺寸标注线、数字、文字（**笔画本身也不算**）
- 轴线端头的圆圈编号、轴线上的短刻度线
- 图框、标题栏、竣工章、图签栏
- 家具、洁具、设备布置符号
- 钢筋排布图案的空隙

**已知的判读分歧点**（写进批次命令，别让判读者自己猜）

1. **带叉方块** —— 必须明说算柱，否则会被判成墙梁
2. **柱编号** —— 若批次禁止读文字，要说明「此时仅凭形状与位置判断」，
   并知道这会**系统性压低**精确率
3. **菱形姿态** —— 旋转的柱仍是柱，必须明说
